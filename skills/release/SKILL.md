# Phase 6 — Release

Follow **core**. Load the stack pack for the release channel. Use the `release-manager`
agent.

1. **Channel**: TestFlight/App Store, Play Console, web hosting, etc. (from the stack pack).
2. **Assets**: screenshots generated by UI tests on the required device sizes; app name,
   subtitle, description, keywords (from the vision and glossary); support URL.
3. **Policies**: privacy policy and terms **drafts**, clearly marked "needs legal review";
   store privacy declarations from the QA privacy audit.
4. **Release notes** from shipped features and the changelog (spec-derive skill,
   release-notes recipe).
5. **Checklist** `.build-my-app/reports/release-checklist.md` — every item with owner
   (Claude / user). Hard stops (accounts, signing, payments, submit) are user-owned; give
   exact step-by-step instructions for each.
6. **Hand-off**: stop and wait for the user to complete their items; verify what can be
   verified (build uploaded, version numbers).

## Gate G6
The user confirms submission/publication. Then `bma_state.py gate release pass`.
